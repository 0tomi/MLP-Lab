# MLP Lab

## Requisitos

- Python 3.12 o 3.13
- Linux o macOS (shell bash)

## Instalar y abrir

```bash
./run.sh
```

La primera vez crea `.venv` e instala las dependencias; después abre el lab en http://localhost:8501.

Dependencias principales: Streamlit, Keras con TensorFlow (CPU), scikit-learn y Plotly.
